# World Cup 2026 Tipping App

A web app where friends predict the results of every World Cup 2026 match and compete on a live leaderboard.

**Live app:** https://worldcup-app-eight.vercel.app

## Features
- Predict the result (1X2) of every group stage match
- Full knockout bracket, including extra time and penalties
- Bonus questions with extra points
- Live leaderboard calculated in the database (SQL function)
- Admin tools to enter match results

## Built with
- React, Vite and Tailwind CSS
- Supabase (PostgreSQL database, authentication, row-level security)
- Vercel (hosting and deployment)
- Claude Code (AI-assisted development)

## What I learned
- How to design a database for a real app with many users
- How to use row-level security to protect data
- How to plan, build and run a product from idea to launch
